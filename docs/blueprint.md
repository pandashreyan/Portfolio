# **App Name**: MotionFolio

## Core Features:

- Project Showcase: Display portfolio projects with title, description, images, and links.
- Animated Transitions: Implement smooth page transitions and animations using Framer Motion.
- Contact Form: Contact form to submit messages.

## Style Guidelines:

- Primary color: Dark navy blue (#24292F) for a professional look.
- Secondary color: Light gray (#F6F8FA) for backgrounds and content areas.
- Accent: Teal (#26A69A) for interactive elements and highlights.
- Clean and modern layout with clear sections for different content types.
- Use subtle animations and transitions with Framer Motion to enhance user experience.
- Use a consistent set of simple, line-based icons for navigation and key sections.
